How it works

Most small browser code editors use two layers: a transparent <textarea> for typing, laid over a <pre> that shows the colors. The two must share exactly the same font, padding, wrapping and scroll position, or the caret drifts away from the text.

CodeJar has only one layer. The highlighted element itself is contenteditable. After each change CodeJar saves the caret, lets your highlighter re-render the HTML, and puts the caret back in the same place.

  • You edit the highlighted code

    No hidden textarea to keep in sync, and nothing to drift out of line.

  • Style tokens any way you like

    Bold, italic, other font sizes and backgrounds all work: no second layer has to match the layout.

  • Wrapping just works

    Long lines wrap the way the browser wraps them.

  • The highlighter sees the caret

    After typing it gets the cursor position, so it can, for example, highlight the matching bracket.

Turn on Outline tokens in the playground above: every outlined token is an element you are typing into.

Usage

import { CodeJar } from 'codejar'
import Prism from 'prismjs'

const highlight = (editor) => {
  editor.innerHTML = Prism.highlight(
    editor.textContent,
    Prism.languages.javascript,
    'javascript',
  )
}

const jar = CodeJar(document.querySelector('.editor'), highlight, {
  tab: '  ',
})

jar.onUpdate((code) => console.log(code))

Give the element a monospace font and white-space is handled for you. Use the CSS tab-size property to control how tabs render.

API

updateCode(code, callOnUpdate = true)
Replace the editor contents.
updateOptions(options)
Change options on the fly.
onUpdate(callback)
Called with the new code after every change.
toString()
Get the current code.
save() / restore(pos)
Save and restore the cursor position or selection.
recordHistory()
Push the current state onto the undo stack.
destroy()
Remove all event listeners.
