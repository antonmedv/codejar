An embeddable code editor
for the browser.

Tiny, zero dependencies, bring your own highlighter. Works with Prism.js, highlight.js, Shiki — or a few lines of regex.

npm i codejar

Options

Try Enter after {, Shift+Tab to outdent, select text and type ( to wrap it.

Tiny

About 3 kB gzipped. No dependencies, no build step needed.

Any highlighter

Pass a function that colors the element — Prism, highlight.js, or your own.

Smart editing

Keeps indentation, auto-closes brackets and quotes, indents with Tab.

Undo & redo

Built-in history that restores both the code and the cursor.

Usage

import { CodeJar } from 'codejar'
import Prism from 'prismjs'

const highlight = (editor) => {
  editor.innerHTML = Prism.highlight(
    editor.textContent,
    Prism.languages.javascript,
    'javascript',
  )
}

const jar = CodeJar(document.querySelector('.editor'), highlight, {
  tab: '  ',
})

jar.onUpdate((code) => console.log(code))

Give the element a monospace font and white-space is handled for you. Use the CSS tab-size property to control how tabs render.

API

updateCode(code, callOnUpdate = true)
Replace the editor contents.
updateOptions(options)
Change options on the fly.
onUpdate(callback)
Called with the new code after every change.
toString()
Get the current code.
save() / restore(pos)
Save and restore the cursor position or selection.
recordHistory()
Push the current state onto the undo stack.
destroy()
Remove all event listeners.
